## ДЗ1: автотесты и общие требования

К ДЗ1 прилагаются тесты в [tests](tests). Положите классы в `submission.py` рядом с тестами и приложите результат запуска к работе:

```bash
pip install pytest torch torch_geometric
pytest tests/test_task1.py -v
```

Блокнот должен выполняться сверху вниз в чистом окружении. Укажите ФИО, группу и выполненные пункты. Для ДЗ1 действуют критерии и снижение баллов из [условия](task1.md); после дедлайна — половина набранных баллов.

Для соревнования действуют отдельные [правила ДЗ2](task2.md): фиксированный дедлайн Kaggle, итоговый private leaderboard и отправка решения преподавателю на почту. Баллы за проект и общая шкала автоматов будут опубликованы отдельно.
