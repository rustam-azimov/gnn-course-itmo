## Автотесты

К заданиям, где нужно реализовать слой, прилагаются тесты в [tests](tests).
Запуск:

```bash
pip install pytest torch torch_geometric
pytest tests/test_task1.py -v
```

Положите свои классы в `submission.py` рядом с тестами. Вывод тестов прикладывается
к сданной работе — работы без прохождения тестов не проверяются.

## Общие правила

- Ноутбук должен выполняться сверху вниз в чистом Colab.
- В начале работы: ФИО, группа, список выполненных пунктов.
- Любой замер качества — не менее 5 запусков с разными сидами, в отчёте среднее и разброс.
- В каждой задаче обязателен baseline, с которым сравнивается основная модель.
- Работа, зачтённая после дедлайна, оценивается в половину набранных баллов.
